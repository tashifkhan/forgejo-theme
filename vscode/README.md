# Forgejo Theme for VS Code

Forgejo Dark and Forgejo Light bring Forgejo's CSS tokens and Chroma syntax
colors to VS Code. The themes cover the workbench, editor, source control,
diffs, notifications, and integrated terminal.

After installation, run `Preferences: Color Theme` and choose Forgejo Dark or
Forgejo Light.

The source, local installation instructions, and license are in the
[GitHub repository](https://github.com/tashifkhan/forgejo-theme).
